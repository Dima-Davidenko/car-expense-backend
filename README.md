# 🚗 Vehicle Expense Tracker App

A mobile application to help users track and manage their vehicle-related expenses efficiently. From fuel logs to service reminders, this app keeps everything organized and accessible across devices.

## ✅ Features

- **Add and View Fuel Expenses:**  
  Log fuel purchases with date, amount, cost, and mileage. View them in a clean, chronological format.

- **Log Repairs and Services:**  
  Record maintenance events such as oil changes, tire rotations, or major repairs.

- **View Statistics and History:**  
  Analyze your spending over time through charts and summaries for both fuel and repairs.

- **Service Reminders (Planned Feature):**  
  Get notified about upcoming maintenance based on mileage or time intervals.

- **Cloud Sync and Authentication:**  
  Securely sync your data across devices using cloud storage and user authentication.

📦 Tech Stack
Frontend: React Native (or your chosen framework)

Backend: Firebase / Supabase (for cloud sync and auth)

Charts: Victory / Recharts / Chart.js (optional)
